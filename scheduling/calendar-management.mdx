Keeping provider calendars accurately configured ensures that patients can book appointments at the right times, front desk staff see correct availability, and online booking only surfaces genuinely open slots. This guide covers everything you need to manage provider schedules — from setting recurring weekly hours to configuring holiday closures across multiple locations.

<Note>
Provider availability settings directly control which time slots appear as bookable through the patient-facing online scheduling portal. If a provider's hours have not been configured, their calendar will show as fully unavailable to patients booking online. Always verify availability settings before enabling online booking for a provider.
</Note>

## Setting Up Provider Availability

Provider availability defines the default working hours during which appointments can be booked. You set availability as a recurring weekly template, which the system uses to populate open slots on the calendar.

### Setting recurring availability

<Steps>
  <Step title="Navigate to Provider Settings">
    In the top navigation bar, go to **Settings** → **Scheduling** → **Provider Availability**. Select the provider you want to configure from the provider list on the left.
  </Step>
  <Step title="Open the Availability Template">
    Click **Edit Availability Template**. The weekly template grid shows all seven days, each with a default state of **Unavailable**. Days shown in blue indicate currently configured working days.
  </Step>
  <Step title="Enable Working Days">
    Click the toggle next to each day the provider works to enable it. The day expands to show time slot configuration.
  </Step>
  <Step title="Set Start and End Times">
    For each enabled day, enter the provider's **start time** and **end time** using the time pickers. These define the outer boundaries of their schedulable hours.

    If the provider takes a lunch break or has a standing block during the day, click **+ Add Break** to define the break period. The system will not allow appointments to be booked during break time.
  </Step>
  <Step title="Configure Visit Type Availability">
    Optionally, restrict which visit types can be booked on specific days. For example, a provider may only accept new patient visits on Tuesdays and Thursdays. Click **Visit Type Restrictions** within a day's settings and check the allowed visit types.
  </Step>
  <Step title="Set the Effective Date Range">
    Under **Template Effective Dates**, set a **start date** for when this template takes effect. If this availability has an end date (e.g., a provider is reducing hours for a set period), set an **end date** as well. You can create multiple non-overlapping templates to handle planned schedule changes in advance.
  </Step>
  <Step title="Save and Review">
    Click **Save Availability Template**. Navigate to the **Schedule** view and verify that the provider's calendar now shows open slots on the correct days and times. Confirm that no slots are incorrectly available during blocked or break times.
  </Step>
</Steps>

## Blocking Time Off

Use time blocks to mark periods when a provider is unavailable without affecting their recurring availability template. Blocks are ideal for vacations, CME days, personal appointments, and other one-off absences.

To add a time block:

1. Navigate to **Schedule** and select the provider's calendar.
2. Click and drag across the time range you want to block, or click **+ New Block** in the upper-right corner.
3. In the **New Block** panel, set:
   - **Title** — a label visible to scheduling staff (e.g., "CME Conference", "Vacation", "Admin Time").
   - **Start date/time** and **End date/time**.
   - **Block type**:
     - **Hard Block** — prevents any appointment from being booked during this time and displays a "Provider Unavailable" message in online booking.
     - **Soft Block** — displays a visual indicator on the internal calendar but still allows manual appointment booking. Useful for reserving time for specific visit types without fully closing the slot.
   - **Notes** — an optional internal note visible only to scheduling staff.
4. Toggle **Notify Care Team** if you want the provider's care team members to receive a notification about the absence.
5. Click **Save Block**.

Blocks appear on the calendar in a hatched gray pattern. To remove a block, click it and select **Delete Block**.

## Holiday Schedules

Holiday schedules let you close your entire organization — or specific locations — on designated holidays without manually blocking each provider's calendar individually.

### Configuring a holiday schedule

1. Go to **Settings** → **Scheduling** → **Holiday Schedules**.
2. Click **+ New Holiday Schedule** and give it a name (e.g., "Standard US Holidays 2025").
3. Click **+ Add Holiday** for each closure date:
   - Enter the **holiday name** and **date**.
   - Select whether the closure is **Full Day** or set custom **open/close times** for a partial closure.
   - Choose the **locations** this holiday applies to. You can apply it to all locations or select specific sites.
4. Click **Save Holiday Schedule**.
5. Under **Assign Schedule**, select the providers and locations that should follow this schedule and click **Apply**.

When a holiday closure is active, any existing appointments scheduled on that day are automatically flagged in the **Scheduling Conflicts** queue. Your team can then contact affected patients and reschedule.

## Multi-Location Calendars

If your organization operates across more than one physical location or clinic site, each provider can have distinct availability configured per location.

### Assigning a provider to multiple locations

1. Go to **Settings** → **Providers** and open the provider's profile.
2. Under **Locations**, click **+ Add Location** and select the site from the dropdown.
3. Repeat for each location where the provider sees patients.
4. Click **Save**.

### Setting location-specific availability

Once a provider is assigned to multiple locations, their availability template separates into location-specific tabs.

1. Go to **Settings** → **Scheduling** → **Provider Availability**, select the provider, and click the location tab (e.g., **Main Clinic**, **Satellite Office**).
2. Configure the availability template for that location independently.
3. Repeat for each location.

On the main Schedule view, use the **Location** filter to display only the calendar for a specific site. Patients booking online are asked to select a location before seeing available providers and times.

### Viewing all locations simultaneously

Click **Multi-Location View** in the top-right of the Schedule screen to see all locations side by side in a split-column layout. This view is useful for identifying gaps in coverage or redistributing patient demand across sites.
