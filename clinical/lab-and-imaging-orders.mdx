Ordering labs and imaging directly from the EHR creates a closed-loop workflow: orders are transmitted electronically to the performing laboratory or radiology facility, results are returned automatically to the patient's chart, and critical values trigger immediate alerts to the ordering provider. This eliminates fax-based result chasing and ensures every result is documented, acknowledged, and acted upon in the patient's record.

## Placing a Lab Order

<Steps>
  <Step title="Open the order entry panel">
    From within an open encounter note, click **+ Order** in the Plan section and select **Laboratory**. You can also place a lab order outside of an encounter by navigating to the patient's chart, selecting the **Orders** tab, and clicking **+ New Lab Order**.
  </Step>
  <Step title="Search for the test">
    Type the test name, common abbreviation, or LOINC code in the **Test Search** field. For example, type "CBC", "hemoglobin A1c", or "metabolic panel." The search returns matching tests from your connected reference laboratory's compendium.
  </Step>
  <Step title="Select the test">
    Click the test name to add it to the order. If the test has required sub-components or reflexive add-ons (for example, a reflex TSH if free T4 is abnormal), a configuration panel appears automatically.
  </Step>
  <Step title="Choose the performing laboratory">
    If your practice is connected to more than one reference laboratory, select the **Performing Lab** from the dropdown. The system highlights your practice's default laboratory automatically.
  </Step>
  <Step title="Enter clinical information">
    Complete the **Diagnosis / ICD-10** field — this is required for most insurance-covered tests and is transmitted to the lab with the order. Add any **Special Instructions** or **Clinical Notes** the lab needs to process the specimen correctly.
  </Step>
  <Step title="Set specimen collection details">
    Select the **Collection Method**: **In-Office Collection** (your staff draws the specimen), **Patient Service Center** (the patient goes to a lab draw station), or **Home Collection Kit** (applicable for certain tests). Set the **Priority**: Routine, STAT, or ASAP.
  </Step>
  <Step title="Review and submit the order">
    Review the order summary — test name, performing lab, diagnosis, and collection method. Click **Submit Order** to transmit the order electronically. A requisition number is generated and stored in the patient's chart.
  </Step>
</Steps>

<Note>
  **In-house vs. send-out orders:** If your practice operates an in-house laboratory (for example, a CLIA-waived point-of-care testing setup), select **In-House** as the performing lab. In-house results are entered manually by your staff and linked to the order. Send-out orders are transmitted electronically to external reference labs and results are returned automatically via the HL7 interface. In-house and send-out orders appear in the same **Orders** tab in the patient chart but are distinguished by a **In-House** or **Reference Lab** badge.
</Note>

<Tip>
  Use **Order Sets** to place multiple related tests with a single click. For example, a "Diabetes Management Panel" order set might include HbA1c, fasting glucose, comprehensive metabolic panel, lipid panel, and urine microalbumin — all ordered simultaneously. See [Order Sets for Common Diagnostic Panels](#order-sets-for-common-diagnostic-panels) below.
</Tip>

## Placing an Imaging Order

The imaging order workflow follows the same pattern as lab orders, with additional fields for imaging-specific requirements like modality, body part, laterality, and clinical indication.

<Steps>
  <Step title="Open the imaging order panel">
    From within an encounter note, click **+ Order → Imaging**. Or navigate to the patient's **Orders** tab and click **+ New Imaging Order**.
  </Step>
  <Step title="Select the modality and study">
    Choose the imaging **Modality** (X-ray, CT, MRI, Ultrasound, Nuclear Medicine, PET, Mammography, Fluoroscopy) and then search for the specific study within that modality — for example, "CT Chest with Contrast" or "Right Knee X-Ray 2 Views."
  </Step>
  <Step title="Specify body part and laterality">
    Confirm the **Body Part** and, where applicable, select **Laterality** (Left, Right, or Bilateral). Incomplete laterality information is a common cause of imaging order rejections.
  </Step>
  <Step title="Enter the clinical indication">
    Complete the **Clinical Indication** field with the reason for the study in plain language (for example, "Rule out pulmonary embolism in patient with pleuritic chest pain and tachycardia"). Many imaging facilities and insurance payers require this field for prior authorization.
  </Step>
  <Step title="Select the imaging facility">
    Choose the **Performing Facility** from the dropdown list of connected radiology partners. The system displays facilities by distance from your practice and indicates which facilities accept electronic orders.
  </Step>
  <Step title="Check for prior authorization requirements">
    The system automatically checks whether the payer requires prior authorization for the selected study. If required, a **PA Required** badge appears — click **Start Prior Authorization** to initiate the process before the patient schedules their imaging appointment.
  </Step>
  <Step title="Submit the order">
    Click **Submit Order**. The order is transmitted to the imaging facility. The patient receives an automated notification through the portal or by SMS with instructions for scheduling their appointment at the selected facility.
  </Step>
</Steps>

## Viewing Pending Orders

Track the status of all outstanding lab and imaging orders from the patient's chart or from your practice-wide order management queue.

**From the patient chart:**

1. Open the patient's chart and go to the **Orders** tab.
2. Use the **Status** filter to view orders by status: **Pending**, **Collected**, **In Progress**, **Resulted**, or **Canceled**.
3. Click any order to view its full detail, including the requisition number, ordering provider, ordered date, and current status message from the performing lab or facility.

**From the practice order queue:**

1. Navigate to **Orders → Pending Orders** in the main navigation.
2. The queue displays all outstanding orders across all patients, sortable by order date, provider, priority, and status.
3. Use the **Priority** filter to surface STAT orders at the top of the queue.

<Info>
  Orders that remain in **Pending** status beyond the expected turnaround time for that test are highlighted in the queue. Expected turnaround times are set in **Settings → Orders → Laboratory Interfaces** and can be customized per connected lab.
</Info>

## Reviewing Results in the Patient Chart

When a lab result or imaging report is returned, it is automatically filed to the patient's chart and routed to the ordering provider's inbox for review.

### Reviewing lab results

1. Open the result notification from **Inbox → Lab Results** or navigate to the patient's **Results** tab directly.
2. The result view displays each analyte with its **value**, **reference range**, and a flag if the value is **High (H)**, **Low (L)**, **Critical High (CH)**, or **Critical Low (CL)**.
3. Click **Trend** next to any analyte to see a historical graph of that value over time — useful for tracking chronic disease markers like HbA1c or creatinine.
4. Document your review and any follow-up actions in the **Result Review** field. This field is required before you can mark the result as **Reviewed**.
5. Click **Mark as Reviewed** to close the inbox item. Your acknowledgment, timestamp, and any notes are stored permanently in the patient's chart.

### Reviewing imaging reports

1. Open the report notification from **Inbox → Imaging Reports**.
2. The full radiology narrative report is displayed alongside any linked images (if your practice uses the integrated PACS viewer).
3. Annotate the report with your clinical interpretation and plan using the **Provider Notes** field.
4. Mark the report as **Reviewed** to close the inbox item and acknowledge the result.

<Tip>
  Use the **Result Message to Patient** button to send a portal message to the patient with a plain-language summary of their results. You can use a pre-written template or compose a custom message. Patients receive a notification in the portal — eliminating the need for a follow-up phone call for routine results.
</Tip>

## Critical Result Alerts

When a laboratory returns a result with a critical value — a value so far outside the reference range that it may represent an immediate threat to patient safety — the EHR triggers an alert workflow that ensures the value is communicated to the ordering provider without delay.

### How critical alerts work

1. The laboratory flags the result as **Critical** in the HL7 result message.
2. The EHR immediately sends a **push notification** to the ordering provider's mobile device and desktop, regardless of whether the provider is actively using the system.
3. A **Critical Result Alert** banner appears at the top of the patient's chart and in the ordering provider's inbox, marked with a red flag.
4. The provider is required to **acknowledge the critical result** within the timeframe set by your organization's policy (configurable in **Settings → Orders → Critical Alert Policy**). If the result is not acknowledged within the defined window, the system escalates the alert to the covering provider and the practice manager.

### Documenting your response to a critical result

<Steps>
  <Step title="Open the critical alert">
    Click the alert notification or open the result from **Inbox → Critical Results**. The result is displayed with the critical value prominently highlighted.
  </Step>
  <Step title="Review the result in clinical context">
    Review the patient's current medications, recent vitals, and active problems to assess the clinical significance of the critical value.
  </Step>
  <Step title="Contact the patient or care team">
    If immediate patient communication is required, use the **Contact Log** within the alert workflow to document the time, method, and outcome of your communication (for example, "Spoke with patient directly at 14:32; advised to go to ED. Patient verbalized understanding.").
  </Step>
  <Step title="Place follow-up orders if needed">
    Click **+ Add Order** within the critical alert panel to place any urgent follow-up orders — repeat labs, new medications, or a referral — without leaving the alert workflow.
  </Step>
  <Step title="Acknowledge and close the alert">
    Click **Acknowledge Critical Result**. Your acknowledgment timestamp, contact log entry, and any follow-up actions are permanently attached to the result record in the patient's chart.
  </Step>
</Steps>

<Warning>
  Unacknowledged critical results are an accreditation and liability risk. Ensure your practice's critical alert policy defines clear escalation timelines and that all providers understand their obligation to respond promptly. Your compliance officer can review the **Critical Result Acknowledgment Report** under **Reports → Clinical Quality** to monitor compliance across all providers.
</Warning>

## Connecting to Reference Laboratories

Your EHR can interface with multiple reference laboratories simultaneously, allowing you to route different order types to different labs based on your contracting arrangements or clinical preferences.

**Supported interface types:**

<CardGroup cols={2}>
  <Card title="HL7 Bidirectional Interface" icon="arrows-left-right">
    Orders are transmitted electronically from the EHR and results are returned automatically. This is the preferred interface type — it eliminates manual result entry and supports real-time order status tracking.
  </Card>
  <Card title="Direct Requisition (Print)" icon="print">
    For labs that do not support HL7 interfaces, the EHR generates a formatted paper or PDF requisition. Results from these labs must be manually entered or scanned and attached to the order record.
  </Card>
</CardGroup>

**To connect a new reference laboratory:**

1. Navigate to **Settings → Orders → Laboratory Interfaces** and click **+ Add Laboratory**.
2. Search the directory of pre-configured laboratory partners (includes Quest Diagnostics, LabCorp, BioReference, Sonic Healthcare, and hundreds of regional labs).
3. If your lab is in the directory, click **Request Connection**. Your account manager will coordinate the interface setup, which typically takes 5–10 business days.
4. If your lab is not in the directory, click **Custom Interface Request** to submit the lab's HL7 specifications to the EHR integration team.
5. Once the interface is active, set the lab as **Default** for specific order types in **Settings → Orders → Routing Rules**.

<Note>
  Interface setup for a new reference laboratory requires a one-time configuration fee and may require a signed data sharing agreement between your practice and the reference laboratory. Contact your account manager for details.
</Note>

## Order Sets for Common Diagnostic Panels

Order sets let you place multiple related tests simultaneously with a single action — saving time and reducing the risk of forgetting a component of a standard diagnostic workup.

<Tip>
  Build order sets for your highest-volume diagnostic scenarios and share them with your entire practice. A well-designed order set for a condition like newly diagnosed type 2 diabetes or a pre-operative evaluation can save 3–5 minutes per encounter and improve diagnostic completeness across your team.
</Tip>

### Creating an order set

1. Navigate to **Settings → Orders → Order Sets** and click **+ New Order Set**.
2. Name the order set (for example, "Annual Diabetes Panel") and assign it a **Category** (Laboratory, Imaging, or Mixed).
3. Add tests by searching the order catalog and clicking **+ Add to Set**.
4. Set default values for each test: priority, collection method, and diagnosis code. Providers can override these defaults at the time of ordering.
5. Set **Sharing** to **Practice** to make the order set available to all providers in your organization.
6. Click **Save Order Set**.

### Using an order set

During an encounter, click **+ Order → Order Sets** and select the set you want to use. All tests in the set are added to the order queue simultaneously. Review the pre-filled details, make any per-patient adjustments, and click **Submit All Orders**.

### Commonly available order sets

| Order Set | Included Tests |
|---|---|
| **Diabetes Management Panel** | HbA1c, fasting glucose, CMP, lipid panel, urine microalbumin/creatinine ratio |
| **Annual Wellness Labs** | CBC, CMP, lipid panel, TSH, vitamin D, HbA1c (if diabetic), urinalysis |
| **Pre-Operative Panel** | CBC, BMP, PT/INR, type and screen, EKG (if indicated), chest X-ray (if indicated) |
| **Hypertension Workup** | BMP, CBC, urinalysis, lipid panel, EKG |
| **Thyroid Workup** | TSH, free T4, free T3 (if clinically indicated), thyroid antibodies |
| **STI Screening Panel** | GC/chlamydia NAAT, RPR/syphilis, HIV, hepatitis B surface antigen, hepatitis C antibody |
